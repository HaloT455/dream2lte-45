# Vô Thường Live Wallpaper — Kotlin

Bản viết lại bằng Kotlin thuần Android SDK.

- Chọn Bạch / Hắc Vô Thường.
- Preview kéo trái/phải.
- Auto idle.
- Tóc/tà áo lay nhẹ.
- Linh khí + hạt sáng.
- Live WallpaperService native.
- Không cần mạng khi chạy.
- Không AndroidX, không thư viện runtime ngoài.
