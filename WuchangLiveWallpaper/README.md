# Wuchang Live Wallpaper

Android live wallpaper for Bạch Vô Thường / Hắc Vô Thường.

Features:
- MOBA-style hero preview with small left/right turn;
- automatic idle rotation / breathing;
- subtle hair movement and lower-cloth sway;
- floating energy ribbons and particles;
- live wallpaper service at 30 FPS while visible;
- launcher-page parallax;
- one-tap system live-wallpaper picker;
- all character assets local: no runtime network dependency.
