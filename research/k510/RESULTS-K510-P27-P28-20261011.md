# Alice K510 P27/P28 – SM-G955F research boot pathway (2026-10-11)

Source branch: `experimental/k510-p28-g955f-preboot-diagnostics`, based on P27/P24/P23; target Linux **5.10.262**; known-good phone kernel is V12R5T **4.4.302**.

## Native Exynos8895 fixes in P27

The pinned original Samsung 4.4 kernel exposes vendor UFS HCI `0x11121100`, UniPro `0x11110000`, PMA `0x11124000`, PMU PHY isolation `0x16480724`, coherency `0x11020700` and reference TCXO selection `0x11021150`.

P27 repairs missing DT clock phandles, reusing **actual Linux v6.13 Exynos8895 FSYS0** identifiers (`CLK_GOUT_FSYS0_UFS_EMBD_I_ACLK`, `CLK_GOUT_FSYS0_UFS_EMBD_I_CLK_UNIPRO`), and assigns `samsung,pmu-phandle = <&pmu_system_controller>` to the experimental DT node. It also resolves the resulting `ctx->pmu` through `syscon_regmap_lookup_by_phandle()` in the P24 Linux 5.10 UFS binder. All runtime verification flags remain false. The UFS node is **status=disabled**.

**Known hard-blocker:** The original Samsung VCC is `vcc-supply=<&ufs_fixed_vcc>`, an always-boot-on **GPIO fixed regulator** tied to `gpg0[0]`. A matching Linux 5.10 supplier is intentionally **not** introduced in the research DTS, because a regulator node can probe independently of the disabled UFS node and toggle the boot-critical storage supply. ACPM, Speedy and S2MPS17 power sequencing are not established by successful compiler/linker tests.

## Why this cannot be called Android 16/One UI 8 boot

1. R1/R2 actual phone trials previously hung at the Samsung splash screen with no verified Linux 5.10 entry; a CI-generated boot image does not repair that pre-Linux ambiguity.
2. No independent evidence of SM-G955F S-Boot -> uniLoader -> kernel transition, or validated pre-Linux UART/debug markers.
3. Exynos8895 UFS cannot probe: node is disabled; fixed regulator and PMIC/SMC/crypto/clock runtime ownership are unverified.
4. Initramfs used here is a debug heartbeat, **not** Android init and not a ported One UI 8 vendor/system ramdisk.
5. Boot packaging, Samsung signature/security and exact S-Boot RAM ownership remain unvalidated for a new flash.
6. A verified original 40 MiB V12R5T BOOT backup is required before physical experimentation: SHA256 `76ab5c78bb475eba5fb994bd7a6269c693a652e6698eb68fbd9f5c858c176823`. User's original backup must remain private.
