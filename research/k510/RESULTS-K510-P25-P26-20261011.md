# P25 / P26 – UFS field-evidence and BOOT flash-readiness gate

## Current engineering status, 11 October 2026

P24 has an actual compiled native Linux 5.10 `platform_driver` and `ufshcd_pltfrm_init()` path for Exynos8895, but the experimental DTS has `status="disabled"` and an audit property is **intentionally absent**. Firmware/ACPM/GPIO/secure-storage validation flags are false. This kernel must not be flashed.

### P25: non-invasive hardware evidence collection

Run **on the working V12R5T Samsung SM-G955F** from the Zorin ThinkPad after ADB is connected:

```bash
bash research/k510/p25-collect-working-ufs-readonly.sh
```

The script only reads selected model/build properties, UFS sysfs paths, Device Tree paths, UFS IRQs, filtered dmesg (optional root) and UFS-related regulator summary. No settings changes, writes, recovery commands, bootloader unlock, repartition or flash operations. The device log archive remains on the user's computer and should be reviewed for sensitive data before sharing.

Actual Linux 5.10 UFS startup requires additional hardware validation; a working V12R5T log alone cannot validate Linux 5.10 power sequencing.

### P26: explicit boot artifact safety gate

```bash
python3 research/k510/p26-boot-test-readiness.py /path/to/local/evidence --report /path/to/local/readiness.json
```

This always refuses to authorize a flash and separately records evidence needed for a diagnostic kernel Image, exact SM-G955F rev05 DTB, uniLoader, debug ramdisk, genuine pre-Linux stage and 5.10 execution, 5.10 UFS read-only enumeration, real ACPM/Speedy/S2MPS17 and FMP/SMC validation, plus the verified local BOOT rollback.

The original working 40MiB V12R5T BOOT backup has documented SHA-256:
`76ab5c78bb475eba5fb994bd7a6269c693a652e6698eb68fbd9f5c858c176823`. Do not upload that raw binary to the public repository.

Prior research had already built 40MiB diagnostic boot files (P2G/P7), but **R1 and R2 hung at the static Samsung logo with no reliable 5.10 origin logs**. Therefore `able to package a debug BOOT` must not be advertised as `boot proven / safe to flash / Android 16 ready`.
