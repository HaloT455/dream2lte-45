### Source audit: P23 corrects a power supply assumption

Samsung original `arch/arm64/boot/dts/exynos/exynos8895.dtsi` has `vcc-supply=<&ufs_fixed_vcc>`. The supply is `compatible="regulator-fixed"`, on `gpio=<&gpg0 0 0>`, marked `regulator-boot-on`. This is **not** a proven directly mapped S2MPS17 output rail. P23 uses Linux regulator framework for the original fixed VCC; its ACPM/Speedy/S2MPS17 gate must be checked separately.

Pinned Exynos8895 UFS 4.4 MMIO: standard HCI `0x11120000`, vendor HCI `0x11121100`, UniPro `0x11110000`, protector `0x11130000`, PHY PMA `0x11124000`; PHY isolation `0x16480724`; sysreg IO coherency `0x11020700` bits 8 and 9; TCXO mux `0x11021150` bit 0. Vendor clock names `GATE_UFS_EMBD`, `UFS_EMBD`.

### New real C source units (Linux 5.10 ABI)

- `research/k510/p23-ufs8895-host.c`, `.h`: typed `struct ufs_hba_variant_ops` table `alice_8895_variant_ops` with native callbacks:
  - `.init` and `.exit`: regulator-fixed VCC enable, HCI/UniPro clocks, sysreg bit-preserving setup, PHY isolation, P22 secure SMCCC; reverse rollback on failure.
  - `.hce_enable_notify`: vendor HCI SW reset bits and a 1ms bounded poll, device GPIO_OUT low/5us/high.
  - `.link_startup_notify`: invokes P21 real 124-entry PHY/UniPro interpreter phases 0/1, check return codes.
  - `.pwr_change_notify`: maps native UFS negotiated PWM/HS mode, A/B rate, lanes and gears into vendor P21 phase 2/3/4/5/6, explicitly rejects unsupported modes.
  - `.setup_clocks`: P21 phases pre-clock-off 7 and post-clock-on 8, leaving UFS framework in charge of actual clock gating.
  - `.suspend` and `.resume`: `-EOPNOTSUPP` until hardware power-state safety has been proven, rather than risking live UFS storage loss.
- `alice_8895_host_validate()` checks physical/regulator resources and all verified-condition flags before a single MMIO write. Defaults to `-EPERM`. It preflights P21 calibration.
- `alice_8895_get_host_ops()` exposes the **compiled** variant callback table; there is **no platform driver, no device ID match, no probe, and no caller to attach the returned table**.
- `p23-audit-ufs-power.py` cross-checks actual donor DT and native Linux 5.10 host callback ABI; produces machine-readable JSON.
- `p23-stage-ufs8895-host.sh` stages into disposable 5.10 Kbuild. CI checks AArch64 C object and full real `vmlinux`, DTB `status=disabled`, and expected symbols.

### Explicit limitations and safety

This is a kernel compilation / callback integration milestone, **not** validated device operation. ACPM/Speedy/S2MPS17 actual runtime readiness, GPIO ownership and regulator enable, Exynos8895 PHY isolation access, secure firmware ABI, FMP encryption mode and Android boot have **not** been demonstrated. Mandatory flags cannot be manufactured or inferred from compilation; they must be independently verified by a future board-specific binding.

**No P23 hardware probe, no UFS DT enablement, no flashable boot.img and no write to the working S8+.**
