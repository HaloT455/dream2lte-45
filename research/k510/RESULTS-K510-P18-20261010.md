## Proven findings

1. Source-exact original Exynos8895 UFS device-tree \`samsung,exynos-ufs\` vs native Linux 5.10 \`samsung,exynos7-ufs\`: not equivalent at runtime. The experimental UFS node remains explicitly \`disabled\` in built DTB.
2. Original ACPM mailbox AP2APM base \`0x16440000\`, firmware SRAM base \`0x16500000\`, IRQ SPI39 and initdata-base \`0x2850\` inventoried.
3. S2MPS17 regulator depends on ACPM IPC channel 2 and proprietary Samsung Speedy I²C. The Speedy controller/runtime is NOT ported.
4. UFS four register windows: HCI \`0x11120000\`, vendor-specific \`0x11121100\`, UniPro \`0x11110000\`, protector \`0x11130000\`. Supply \`ufs_fixed_vcc\`. Original clock names \`GATE_UFS_EMBD\` and \`UFS_EMBD\`.
5. Ten original PHY/UniPro tuning arrays extracted, counted and individually SHA-256 pinned in \`p18-hardware-audit.json\`: 31 PHY init, 9 post PHY init, 20 PWM, 27 HS rate A, 27 HS rate B, 1 each post-calib HS A/B, 3 pre-clock-off, 3 post-clock-on, 2 lane1-SQ-off = **124 entries**. These are **not written to hardware**.
6. Real Linux 5.10.262 generic \`drivers/scsi/ufs/ufs-exynos.o\` and \`drivers/phy/samsung/phy-samsung-ufs.o\` compiled successfully, and a disabled-UFS DTB compiled.
7. The original 2,420-line V12R5T \`ufs-exynos.c\` was compiled in an isolated disposable test directory against actual 5.10 headers. Exact donor PM/CAL, M-PHY and UniPro header dependencies were imported, not replaced by stubs.

## Critical unresolved kernel API compatibility

The real donor UFS object result is **\`VENDOR_4_4_TO_5_10_API_PORT_BLOCKED\`** (compiler exit 2). Excerpts from final P18 CI:
- Samsung secure-monitor calls: \`exynos_smc\`, \`SMC_CMD_FMP_SECURITY\`, \`ID_FMP_UFS_MMC\`, \`FMP_DESCTYPE_0\`, \`SMC_CMD_SMU\`, \`FMP_SMU_INIT\` and \`SMC_CMD_LOG\` not available with the same interfaces in native 5.10.
- UFS quirk constants have changed (\`UFSHCD_QUIRK_BROKEN_DWORD_UTRD\`, \`UFSHCD_QUIRK_USE_OF_HCE\`, \`UFSHCD_QUIRK_GET_UPMCRS_DIRECT\`, etc.).
- Removed or changed \`struct ufs_hba_variant_ops\` callbacks (\`host_reset\`, \`pre_setup_clocks\`, \`set_nexus_t_xfer_req\`, \`set_nexus_t_task_mgmt\`, \`get_unipro_result\`); required port to modern callback semantics, not merely cast/signature changes.
- \`struct ufs_hba_variant\` layout and \`struct ufs_hba.monitor\` missing; \`struct ufs_pa_layer_attr.peer_available_lane_tx\` changed.
- Samsung \`pm_qos_*\` and \`PM_QOS_DEVICE_THROUGHPUT\` removed/changed; \`ufshcd_pltfrm_exit\` no longer direct equivalent.
- Several UniPro/L2 timer IDs renamed, e.g. \`FC0PROTTIMEOUTVAL\` versus \`DL_FC0PROTTIMEOUTVAL\`.
