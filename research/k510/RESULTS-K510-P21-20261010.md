# P21 – Exynos8895 UFS PHY/UniPro calibration interpreter for Linux 5.10

Branch `experimental/k510-p21-ufs8895-calibration-engine`. Based on P20, with original donor pinned to `3ea6f1b4341c0bd9e0e020567fa334da4a1a24c3` and Linux 5.10.262. CI: https://github.com/HaloT455/dream2lte-45/actions/runs/38059195718.

## Code implemented

- `research/k510/p21-ufs8895-engine.c` and `p21-ufs8895-engine.h`: proper Linux 5.10 C compilation units with UFS HCD `ufshcd_dme_set` API, original Samsung PHY/UniPro opcodes, phase and lane ordering.
- `research/k510/p21-stage-ufs8895-engine.sh` stages into disposable Linux 5.10 source; `obj-y` final link in the experimental *kernel build*, not the V12R5T donor, and no boot image.
- Preflight checks for MMIO bases/ranges, DME selector width, 1–2 M-PHY lanes, PWM/HS gears, source clocks and callback data. Invalid operation types return `-EOPNOTSUPP`; errors propagate.
- Real Samsung Exynos8895 M-PHY APB clock-stop semantics from original `ufs-exynos.h` `HCI_CLKSTOP_CTRL=0xb0`, `MPHY_APBCLK_STOP=BIT(3)`; PMA lane stride `0x140` in vendor byte address units, not Exynos7's generic PHY scheme.
- Supports DME attribute selectors for common and lane TX/RX PCS; original 4.4 RX selector base 4; period override for PCS RX/TX and UniPro from actual clock rates.
- PLL/CDR PMA lock wait limited to 100ms, returns `-ETIMEDOUT`. No silent timeout passing.
- `alice_ufs8895_check_phase` has no hardware effects; `alice_ufs8895_run_phase` is explicitly blocked unless `allow_hardware_io` is set by a future reviewed hardware driver. P21 supplies **no such caller and no platform driver registration**.

## Verification and limitations

- Exact 10 original DT tables / 124 rows from P20 remain linked in code data.
- CI builds kernel objects with actual AArch64 Linux 5.10.262 GCC and checks `alice_ufs8895_check_phase` and `alice_ufs8895_run_phase` ELF symbols.
- Full `vmlinux`, `System.map`, DTB and seven donor ACPM/S2MPS17 linker symbols are mandatory CI gates. CI success is a compile/link milestone **only**.
- Deliberately does not alter the UFS DT node: `status=disabled`. No SMC/FMP, Samsung Speedy PMIC UFS power, verified secure storage path, actual UFS hardware discovery, Android 16 boot, or flash ZIP.
- Even a successful vmlinux link with the interpreter present does **not** make a bootable Exynos8895 UFS driver. Only after P22/P23 vendor-specific callbacks, secure monitor operations, and power sequencing can the DT binding/hardware probe be considered.

**Safety: do not flash. Preserve existing working V12R5T and user data.**
