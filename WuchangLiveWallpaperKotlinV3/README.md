# Vô Thường Live Wallpaper V3 — Interactive Kotlin

V3 tập trung vào tương tác kiểu Samsung live wallpaper + hero viewer kiểu MOBA.

Công nghệ:
- Kotlin / Android WallpaperService native
- Hardware Canvas (lockHardwareCanvas, fallback Canvas)
- 60 FPS khi visible
- Touch ripple
- Bubble particle physics
- Drag trails
- Touch repulsion field
- Accelerometer parallax
- Launcher page parallax
- Hero idle turn
- Breathing
- Tóc/tà áo sway
- Procedural aura / energy ribbons
- Auto pause khi wallpaper không visible

Không dùng mạng ở runtime và không phụ thuộc AndroidX.
